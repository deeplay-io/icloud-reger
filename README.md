# icloud-codes

Сервис выдачи кодов из писем для пула iCloud-алиасов (Hide My Email).

## Как это работает

- **Родитель** = полноценная iCloud-учётка, залогиненная в браузере (Dolphin Anty / ADS Player) на машине. На одного родителя — до 750 алиасов.
- **Авторегистрация** создаёт алиасы в iCloud со случайными паузами 8–16 минут. Общий лимит ручного и автоматического создания — не больше 5 запросов за любые 60 минут на родителя. При достижении 750 генератор останавливается и ждёт выбора другого родителя. Расписание и отправленные запросы сохраняются в SQLite, поэтому перезапуск не сбрасывает лимиты. В базу попадают только подтверждённые адреса с сайта.
- **API**: тренер просит код для алиаса `***@icloud.com` → сервис находит родителя в БД, в уже открытом браузере находит вкладку iCloud-почты, идёт по свежим письмам от новых к старым, находит письмо **на адрес этого алиаса** и вырезает код настраиваемым паттерном. Ответ: `почта:код`.

Вся автоматика работает **через CDP** (Chrome DevTools Protocol) в уже открытый браузер — ничего не запускает сама.

## Требования

- Node.js 20+
- Browser с включённым remote debugging (Dolphin Anty: включите CDP/отладочный порт, например 9222)
- В браузере залогинены родительские учётки: страница Hide My Email + iCloud Mail

## Быстрый старт

```bash
npm install
npm start                            # сервис без GUI (tsx src/index.ts)
npm run smoke                        # проверка логики без браузера
```

Конфиг: `config.json` в корне проекта (скопируйте из `config.example.json`). Если запустить GUI — он сам создаст `config.json` из примера. Относительные пути `db.file` и `debug.dir` разрешаются от папки, где лежит `config.json`.

## Windows GUI

Electron-приложение: запуск/стоп сервиса, запрос кода в один клик, пул алиасов, ротация родителей, живой лог. Сервис при этом работает как обычный HTTP API (порт 8787) — тренер может ходить и через него.

«Подключить профиль» сам запускает Dolphin Anty, если его локальный API (127.0.0.1:3001) не отвечает: ищет `Dolphin Anty.exe` в `Program Files\Dolphin Anty` и `%LOCALAPPDATA%\Programs`, ждёт готовности API (до 90 с) и первую минуту повторяет открытие профиля, пока Dolphin входит в аккаунт. При нестандартной установке укажите путь в `browser.dolphinPath` в `config.json`. Dolphin запускается независимым процессом и не закрывается вместе с приложением.

### Релизы и автообновление

Установщик собирает GitHub Actions ([.github/workflows/release.yml](.github/workflows/release.yml)) по тегу `v*` и выкладывает в Releases репозитория. Выпустить версию:

```bash
npm version minor          # или patch: меняет версию в package.json, делает коммит и тег
git push --follow-tags
```

Workflow проверяет, что тег совпадает с версией, прогоняет тесты, собирает установщик, проверяет его (better-sqlite3 и gRPC-сервис запускаются в Electron) и публикует `icloud-codes-setup-<версия>.exe` с `latest.yml`.

Локально `npm run dist:win` не запускайте: electron-builder пересоберёт `better-sqlite3` в `node_modules` под Electron, и тесты и сервис на Node 22 перестанут запускаться (вернуть: `npm ci`).

Первая установка на сервер — вручную из Releases. Базу переносить не нужно: источник правды — список «Скрыть e-mail» в iCloud.
1. Установите `icloud-codes-setup-<версия>.exe`, выберите «только для меня» (иначе каждое обновление спросит права администратора).
2. Вкладка «Родители»: e-mail родителя → «Сделать активным».
3. ID профиля Dolphin → «Подключить профиль», затем «▶ Запустить сервис».
4. Алиасы родителя загрузятся из iCloud сами: при запуске сервиса и смене родителя, дальше раз в 6 часов (пока браузер не подключён — повтор каждые 2 минуты). Авторегистрация на новой базе начинает не раньше чем через час: история созданий с другой машины за последний час ей не видна, а лимит Apple — 5 в час.

Дальше:
- Токен для обновлений — fine-grained, владелец `deeplay-io`, только репозиторий `icloud-reger`, право Contents: Read-only. Впишите его в `config.json` как `"update": { "token": "github_pat_…" }` и перезапустите приложение. В установщике и репозитории токена нет.
- Приложение проверяет обновления при запуске и раз в час, скачивает новую версию само, а ставит только по кнопке «Обновить до …»: останавливает сервисы, ставит обновление, перезапускается и снова запускает те сервисы, что работали. Состояние — в чипе «версия», ошибки (например, просроченный токен) — в подсказке чипа и в логе.
- Конфиги и база лежат в `%APPDATA%\icloud-codes\` (`config.json`, `mail-code.json`, `data\codes.db`; кнопки в окне открывают конфиги) и при обновлении не трогаются.
- Сервисы в установленном приложении работают на его же exe (`ELECTRON_RUN_AS_NODE`), Node.js на сервере не нужен.
- gRPC слушает `0.0.0.0:50051`: при первом запуске Windows спросит про доступ к сети. Вместо ответа на запрос создайте правило, пускающее на порт только адреса пилота:

```powershell
New-NetFirewallRule -DisplayName "ICloud Codes gRPC" -Direction Inbound -Protocol TCP -LocalPort 50051 -RemoteAddress <адреса пилота> -Action Allow
```

В окне:
- чипы статуса: сервис / браузер (CDP) / активный родитель / число алиасов / gRPC / версия (обновление каждые 5 с);
- запуск и остановка HTTP-сервиса и gRPC-сервиса, кнопки `config.json` и `mail-code.json`;
- «Запросить код» — поле `***@icloud.com`, результат `почта:код`;
- вкладки: Алиасы (таблица + ручное добавление), Родители (таблица + ротация), Лог сервиса (строки gRPC с пометкой `[gRPC]`), Подключение (адреса машины для gRPC-клиента, внешний IP по кнопке, готовые команды grpcurl и правила файрвола).

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус: CDP, активный родитель, число алиасов |
| GET/POST | `/code?email=*
**@icloud.com` | код; ответ `text/plain`: `email:код` |
| GET | `/aliases` | список алиасов из БД |
| GET | `/parents` | родители + число алиасов |
| POST | `/parent` `{email}` | ротация: сделать родителя активным |
| POST | `/aliases` `{email, name?}` | добавить алиас вручную |

Пример:

```bash
curl 'http://127.0.0.1:8787/code?email=xyz@icloud.com'
# xyz@icloud.com:482913
```

Коды ошибок: 400 — нет/некорректный email; 404 — алиас не в пуле или письмо не найдено; 503 — профиль нужного родителя не открыт / селекторы не настроены; 500 — остальное (см. лог и `debug/`).

## gRPC-сервис кодов для пилота регистрации

Отдельный процесс без браузера: читает ящики родителей по IMAP (`imap.mail.me.com`) и отдаёт коды из писем GGPass по контракту [proto/deeplay/mail_code/v1/mail_code.proto](proto/deeplay/mail_code/v1/mail_code.proto) (`MailCodeService.GetCode`). Запускается на том же Windows-сервере, что авторегистратор, кнопкой «Запустить gRPC» в окне приложения; пилот из кластера только обращается к нему за кодами. Порт открыт без TLS и авторизации, поэтому доступ к нему нужно ограничить файрволом (см. «Релизы и автообновление»). Пока в `mail-code.json` пароль из примера, сервис не запускается.

```bash
cp mail-code.example.json mail-code.json   # вписать родителей и их app-specific пароли
npm run imap:probe                          # вход, папки, последние письма
npm run imap:probe -- --alias xyz@icloud.com --days 30 --save   # письма на алиас + .eml в debug/mail-samples/
npm run grpc                                # сервер, по умолчанию 0.0.0.0:50051, без TLS
npm run grpc:call -- --email xyz@icloud.com --kind SIGN_UP --since-minutes 10 --wait 60
```

- Пароль для IMAP — app-specific (account.apple.com → Вход и безопасность → Пароли приложений). После отказа во входе аккаунт не трогается до перезапуска сервиса, чтобы не заблокировать Apple ID.
- Письма только читаются (EXAMINE + BODY.PEEK): не удаляются и не помечаются прочитанными. Смотрятся INBOX и спам (`\Junk`).
- Письмо подходит, если алиас есть в To/Cc/Delivered-To/X-Original-To, оно пришло на сервер (INTERNALDATE) не раньше `sent_after_unix_ms` и относится к запрошенному виду. Берётся самое новое; если код из него не вырезан — FAIL, а не код из старого письма.
- Вид письма (`kinds.CODE_KIND_SIGN_UP` / `CODE_KIND_MFA`): правило по отправителю, теме и тексту; письмо, подходящее под оба правила, не отдаётся. **Текущие правила — черновик**, уточнить по реальным письмам GGPass.
- Реестра алиасов в сервисе пока нет: письмо ищется во всех ящиках из `imap.accounts`, UNKNOWN_MAILBOX — только для чужого домена (`domains`).
- Запасной путь — браузер (`browser` в `mail-code.json`, включён по умолчанию): если родитель алиаса не читается по IMAP (нет пароля в конфиге, отказ во входе, нет сети), код читается из iCloud Mail в подключённом профиле Dolphin через HTTP-сервис этого же окна (`POST /mail/messages`). Родителей с исправным IMAP HTTP-сервис пропускает по своей базе, не открывая браузер. Ограничения: только родитель, чей профиль подключён и активен; только открытая папка (обычно «Входящие», без спама); один проход по почте на алиас не чаще `pollIntervalMs` (15 с), проходы идут по очереди с созданием алиасов; открытые письма становятся прочитанными; время письма — из заголовка с точностью до минуты, поэтому `sent_after` округляется вниз до минуты. Нужны запущенный HTTP-сервис и алиас в базе.
- Есть reflection (для `grpcurl -plaintext`) и `grpc.health.v1.Health` (для проверок доступности).

## Конфиг (config.json)

- `parent.email` — e-mail **текущей активной** родительской учётки (обязательно).
- `browser.cdpUrl` — адрес CDP открытого браузера (`http://127.0.0.1:9222`).
- `browser.hideMyEmailUrl` / `mailUrl` — куда ходить, если вкладки ещё нет.
- `browser.hideMyEmailTabHint` / `mailTabHint` — по какому URL в открытой вкладке её искать.
- `generator.enabled` — включение авторегистрации при запуске сервиса.
- `generator.namePrefix` — основа метки (например `mybox`), задаётся также полем «Имя для авторегистрации» на вкладке «Алиасы». Метки идут по максимальному существующему номеру у выбранного родителя: `mybox5` → `mybox6`. Адрес назначает iCloud; `@icloud.com` в метку не добавляется.
- `generator.minIntervalMinutes` / `maxIntervalMinutes` — диапазон случайной паузы (по умолчанию 8–16 минут). Ограничение 5 запросов за 60 минут действует независимо от этих настроек.
- Время следующего создания и число запросов за час отображаются в статусе «авто» и в `/health`. Для работы должны оставаться запущенными сервис и подключённый профиль Dolphin с авторизованным iCloud.
- Ошибка после отправки запроса также занимает слот в часовом лимите: запрос мог выполниться на стороне Apple. Используйте «Загрузить из iCloud» для подтверждения результата.
- `code.patterns` — **настраиваемые** паттерны вырезания кода (см. ниже).
- `code.freshnessMinutes` — не лезем в письма старше этого возраста (если дата читается).
- `code.maxMessagesToScan` — сколько последних писем проверить по запросу.

### Паттерны кода

Массив, пробуются по порядку; первый, вырезавший 4–6 цифр, побеждает:

```json
{ "name": "kod-digit", "regex": "код[^0-9]{0,12}(\\d{4,6})" }
```

- `regex` — код = capture group 1 (или весь match).
- `mustContain` (опц.) — фильтр «письмо вообще про код», чтобы не резать случайные цифры.

Как только станет известен реальный вид письма от Dolphin Anti / ADS Player — подставьте точный regex.

### Интерфейс iCloud

Создание и импорт используют список «Скрыть e-mail» в iCloud → Функции iCloud+. Ручная и автоматическая регистрация используют один механизм и общую блокировку операций. Кнопки и счётчик находятся по разметке страницы (классы, имена полей), а не по подписям, поэтому язык профиля Dolphin значения не имеет. Старые параметры `generator.selectors` и `generator.intervalMinutes` больше не используются.

Для чтения почты настроены `code.selectors.messageItem`, `body` и `subject`. Чтение учитывает отдельные фреймы iCloud Mail, адрес получателя, дату и уже выданные коды. При изменении разметки Apple эти селекторы и обработчики потребуется обновить. Чтение почты пока рассчитано на русский интерфейс iCloud Mail (заголовки «Кому/Тема/Дата», русские месяцы) и на совпадение часового пояса профиля с часовым поясом компьютера.

## Ротация родителя

Когда родитель исчерпан (750 алиасов), сервис сам останавливает генерацию и пишет в лог. Тогда:

1. Откройте в Dolphin Anty профиль с новой родительской учёткой (залогинены Hide My Email + Mail).
2. `curl -X POST http://127.0.0.1:8787/parent -H 'content-type: application/json' -d '{"email":"newparent@icloud.com"}'`
3. Обновите `parent.email` в `config.json` (чтобы пережил перезапуск).

«Загрузить из iCloud» (и автоматическая загрузка при старте сервиса и перед каждым созданием) приводит алиасы активного родителя в базе к списку активных адресов «Скрыть e-mail»: новые добавляются, метки обновляются, отсутствующие в списке (удалённые или деактивированные) удаляются из базы. Пустой список перечитывается повторно, прежде чем очистить алиасы родителя.

Алиасы старых родителей остаются в БД — их коды читаются, только если снова открыть их профиль (`POST /parent`).

